# 运行时本体与状态分离

状态：已接受

工具运行时的可执行文件和标准库与全局包、缓存、用户配置等运行时状态分开管理。第一版只服务当前 Windows 用户，使用便携 CPython；Conda 环境默认仅观测并通过描述文件重建；受管 Node 使用独立全局包前缀；Git 凭据和 SSH 私钥不随运行时迁移；PowerShell 模块和配置文件作为单独状态处理。选择该边界是为了避免把一个版本切换演变成不可控的全量数据搬迁；代价是安装、纳管、备份和删除都需要分别展示运行时本体及其关联状态。

## 后果

- 删除运行时前必须明确列出将被影响的运行时状态。
- 运行时状态不能成为运行时本体正常启动的隐式必需条件，除非适配器明确声明。
- 可移动数据根目录受支持，但磁盘不可用时操作必须被阻止并说明原因。
