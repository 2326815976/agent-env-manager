# Windows 11 桌面端与提权架构

状态：已接受

本产品仅面向 Windows 11 x64，采用 .NET 8、WPF、独立核心库和 CLI，需要管理员权限的操作由按需启动的独立提权助手执行。选择该架构是因为 Windows 注册表、Junction、ACL、进程环境广播和 UAC 是核心能力，而常驻高权限服务会显著扩大攻击面；代价是放弃第一版跨平台能力，并需要维护普通进程与提权助手之间的强类型通信边界。

## 后果

- WPF 只负责界面、确认和进度展示，扫描、安装、迁移、切换及回滚统一由核心库执行。
- 提权助手只接受白名单强类型操作，不接受任意命令或脚本。
- 第一版不提供 Windows 以外的客户端。
