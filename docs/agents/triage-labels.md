# 分诊标签

工程技能使用五个规范分诊角色。本文件将这些角色映射到本仓库问题跟踪器中实际使用的标签字符串。

| 技能中的规范标签 | 本仓库实际标签 | 含义 |
| ---------------- | -------------- | ---- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 issue |
| `needs-info` | `needs-info` | 正在等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整定义，可交由自主 agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要由人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个角色，例如“应用适合自主 agent 的分诊标签”时，使用表中对应的实际标签字符串。

如果需要适配仓库中已有的标签体系，请修改“本仓库实际标签”列，使技能复用现有标签，而不是创建重复标签。
