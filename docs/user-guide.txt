AgentEnvManager 使用说明
=======================

适用范围
--------
Windows 11 x64。程序为自包含发布，不要求预装 .NET。

第一版范围与限制
----------------
- 依赖卡片：Python、Node.js、Git、PowerShell 7、uv、npm、pnpm、ripgrep、
  GitHub CLI；Conda 与 winget 仅观测，不参与安装与切换。
- Agent 范围：ChatGPT Desktop 与 CC Switch。Codex 作为 ChatGPT 内置的
  工具调用组件处理，不作为独立 Agent 目标。
- 机器级环境变量只读；第一版不提供提权流程。
- 协同迁移（ChatGPT/Codex 配置环境 + CC Switch 配置环境一起迁移，
  含 Junction 重接线与全量回滚）尚未提供执行路径，目前只有迁移计划与
  预检。已纳管环境的单目标迁移不受影响。

启动软件
--------
1. 双击 app\AgentEnvManager.Wpf.exe 启动图形界面。
2. 命令行工具位于 app\cli\AgentEnvManager.Cli.exe。
3. 命令行查看帮助：AgentEnvManager.Cli.exe --help

首次使用
--------
1. 点击“扫描”，查看 PATH、运行时、Agent 配置环境和冲突。
2. 在“环境清单”中选择目标，点击“预览纳管”。
3. 确认影响范围后点击“确认纳管”。
4. 在“操作中心”查看操作记录和恢复点。

运行时管理
----------
1. 打开“运行时管理”，点击“加载提供者”。
2. 选择提供者和版本；需要镜像时可填写镜像地址。
3. 点击“预览安装”，确认安装目录、影响范围和恢复点。
4. 点击“确认安装”。完成后操作中心和恢复点会自动刷新。
5. 离线安装：选择提供者和版本，填写本地制品路径，点击“导入并校验”。
6. 如需指定位置，在“安装目录”填写绝对路径或点击“选择”；留空时使用
   管理器数据根目录。自定义目录必须由本程序创建，回滚时只删除带有
   管理器所有权标记的目录。

环境变量管理
------------
1. 打开“环境变量”，点击“加载环境变量”。
2. 可直接编辑的只有管理器拥有的条目：已纳管入口，以及以
   AGENT_ENV_MANAGER_ 开头的变量。
3. 其他用户变量、机器级变量与外部 PATH 条目为只读；机器级变量在第一版
   不提供写入入口。
4. 勾选需要写入用户 PATH 的已纳管入口。
5. 点击“预览变更”，确认影响范围后点击“应用变更”。
6. 应用前会创建恢复点；用户手改的 PATH 条目和无关变量不会被覆盖。
7. 需要撤销时，在“操作中心”对已完成的环境变量事务执行回滚，原值会从
   恢复点恢复。

迁移与回滚
----------
1. 在“环境清单”选择已纳管环境。
2. 打开“迁移”，填写目标路径。
3. 点击“预览迁移”，确认影响范围、恢复点和预期结果。
4. 点击“确认迁移”。完成后环境清单、操作中心和恢复点会刷新。
5. 需要恢复时，在“操作中心”选择成功或失败的迁移操作，点击“准备回滚”，
   再点击“确认回滚”。

Agent 绑定
----------
1. 打开“Agent 绑定”，选择 Agent。
2. 点击“发现 Agent”，程序会尽量回填 Agent 配置环境和可执行文件。
3. 选择运行时版本，并设置受管入口和工作区。
4. 点击“预览绑定”，确认绑定文件和配置恢复点信息。
5. 点击“执行绑定”，然后点击“健康检查”。
6. 健康检查失败时，页面会显示是否已恢复原绑定。

CC Switch
---------
1. 打开“CC Switch”标签页，点击“发现 CC Switch”。
2. 页面显示可执行文件、版本、配置根、settings.json、当前 codexConfigDir
   以及 WebView 兼容路径（%LOCALAPPDATA%\com.ccswitch.desktop、
   %APPDATA%\com.ccswitch.desktop）。
3. 填写目标 Codex 配置环境，点击“预览绑定”。
4. 预览只显示将要修改的 codexConfigDir、保持不变的内容、兼容路径和
   恢复点，不显示 provider 密钥或完整配置内容。
5. 点击“应用绑定”。写入采用字段级替换，settings.json 中的注释、未知
   字段与 provider 内容保持原样；失败时会从恢复点还原。

诊断包
------
1. 打开“诊断包”，点击“生成预览”。
2. 逐项审阅脱敏后的诊断内容。
3. 输入本地绝对路径，点击“导出到本地”。
4. 诊断包不包含 Git 凭据、令牌或 SSH 私钥，默认不上传任何状态。

写入和删除前的确认
------------------
- 安装、导入、迁移、回滚、纳管和 Agent 绑定必须先预览再确认。
- CLI 写操作必须带 --confirm。
- 删除默认进入隔离区；永久清除需要再次确认。
- 默认卸载保留状态、工具运行时、恢复点和 Agent 绑定。

数据位置
--------
管理器状态：
%LOCALAPPDATA%\AgentEnvManager

运行时数据：
%LOCALAPPDATA%\AgentEnvManager\data

可用环境变量覆盖：
AGENT_ENV_MANAGER_HOME
AGENT_ENV_MANAGER_DATA_ROOT

排查建议
--------
1. 操作失败时先查看页面状态提示和“操作中心”失败原因。
2. 网络安装失败时检查网络、代理或改用镜像/离线制品。
3. env-vars 默认掩码显示变量值，需要查看真值时显式加 --show-secrets；
   在终端或流水线中打印前请确认其中不含令牌。
4. Agent 无法调用工具时，先确认 ChatGPT 的 CODEX_HOME 指向真实配置环境，
   并检查 %APPDATA%\Codex 与 %LOCALAPPDATA%\Codex 兼容 Junction 是否存在。
5. CC Switch 绑定前请确认其进程已停止，避免运行中的实例覆盖 settings.json。
6. 可生成诊断包后人工审阅，再用于排查问题。
7. 重要环境在迁移或删除前先确认存在有效恢复点。

恢复点
------
- 运行时安装/切换、环境变量事务、纳管、迁移、删除与 Agent 绑定都会在
  写操作前记录恢复点。
- 恢复点保存在管理器状态目录（%LOCALAPPDATA%\AgentEnvManager\recovery
  及 recovery\environment-variables），默认卸载不会删除它们。
- 操作中心可对失败的迁移/安装/绑定，以及已完成的环境变量事务与迁移
  执行回滚。
